## 项目定位

moonbit-sat 是纯 MoonBit 实现的 CDCL SAT 求解器，把判定、证明、优化连成一条可验证的链路：读入 DIMACS CNF 判断公式可满足性；不可满足时输出 DRAT 风格日志，仓库内另带一个独立的检查器逐条复算；读入 WCNF 做加权 MaxSAT，给出最小违约成本。

MoonBit 生态里已有的两个 SAT 包各自缺一块能力：`AdUhTkJm/sat-solver` 用 CDCL 但只支持 native 目标，也不产出证明；`yf666888/moonsatkit` 支持四后端但是 DPLL，同样没有证明和加权优化。`clbbbb/lrat-check` 只有检查器没有求解器。本项目在同一仓库里完成求解与验证，四后端一致。

## 三个完整使用场景

1. **形式化验证工具的判定后端。** 在 MoonBit 里写模型检验或符号执行时，把路径条件编码成 CNF 交给 `Solver`；路径不可达时保留证明日志，用仓库自带的检查器复核结论，而不是只有求解器的自我声明。
2. **配置与排班的加权优化。** 把必须满足的约束写成硬子句、偏好写成带权软子句，生成 WCNF 交给 `maxsat_solve`，得到最小违约成本，用来比较不同排班或资源分配方案。
3. **算法课程与练习的参照实现。** 教学需要一份逻辑完整、可读、可跑的 CDCL 实现；本项目的两文字监听、1-UIP、VSIDS、重启、归约都在单个文件内，配 24 个测试与真值表对拍，可以作为学生作业的参照或起点。

## 核心功能

- 解析与输出 DIMACS CNF；声明的变量数少于实际出现时自动扩大，不报错。
- CDCL 搜索：两文字监听传播、1-UIP 冲突分析与学习子句、VSIDS 变量活跃度、相位保存、线性增长重启、按 LBD 与活跃度归约子句库。
- 增量求解：`solve(assumptions)` 可重复调用；假设冲突返回 false 但不改变求解器状态，后续调用照常工作；`add_clause` 支持追加约束。
- 不可满足时输出 DRAT 风格日志，包含学习子句、删除行与终结空子句。
- 独立检查器：`parse_drat` / `check_drat` / `verify_proof`，不引用求解器代码，逐条 RUP 复算，非 RUP 步骤与缺失空子句都会被拒绝。
- 加权 MaxSAT：松弛变量 + 按权重展开 + Sinz 顺序计数编码，对成本做二分求最优。
- 预处理 `Formula::simplify`：去掉子句内重复文字、删除重言子句，并返回删除条数。
- 命令行四个子命令：`solve` / `proof` / `verify` / `maxsat`，参数里用 `;` 代替换行，公式直接内联。

## 技术方案

核心库用纯 MoonBit 编写，不依赖外部求解器，也不调用 FFI。模块按职责拆分：`lit.mbt` 负责字面编码（`2 * var + sign`，0 基稠密下标），`cnf.mbt` 负责子句结构、DIMACS 解析与预处理，`solver.mbt` 负责 CDCL 搜索与证明记录，`checker.mbt` 负责独立的 DRAT 解析与 RUP 校验，`maxsat.mbt` 负责 WCNF 解析与最优化。

依赖是单向的：求解器不引用检查器，检查器不引用求解器，二者只共享字面编码与公式解析。这样证明的成立与否不依赖求解器的内部状态，校验才有意义。

测试覆盖四类：80 轮随机小公式与真值表枚举对拍（SAT 时校验模型）；40 轮随机 UNSAT 实例的证明由独立检查器逐条复算；40 轮随机 WCNF 的最优成本与暴力枚举比对；另有 11 个边界测试，覆盖空公式、空子句、重复文字、重言子句、变量越界、证明删除行、连续假设调用等退化输入。

四个后端 `moon build` 全部成功，wasm 与 js 后端的同一套 24 个测试全部通过。

## 原创性与生态定位

Mooncakes 上已有两个 SAT 相关包，都与本项目的能力边界不重叠：一个是仅 native 的 CDCL、无证明，一个是四后端的 DPLL、无证明与加权优化。生态中可校验的 UNSAT 证明与加权 MaxSAT 目前是空白，本项目补的正是这两块。

与「零依赖」「统一 API」这类理由不同，本项目的立论建立在具体能力上：证明日志可以被第三方检查器复算，加权优化能给出最小违约成本，两者在其他包里都没有。

项目面向验证、调度、教学三类使用者，不是只服务单一包维护者的小工具。

## 范围边界

证明只输出 RUP 步骤，不支持 RAT；检查器遇到 RAT 会拒绝而不是放过。MaxSAT 的总软权重有上限，超过时直接报错，不做截断，因为截断会给出错误的最优成本。预处理只做到子句内去重与重言消除，没有变量消除与子句自吸收；没有并行。重启为线性增长，尚未替换为 Luby 序列。命令行不支持文件 IO（MoonBit core 暂无文件系统模块），改为内联文本传参。没有与 MiniSat、CaDiCaL 这类工业求解器做过性能比较，本项目看重的是生态内的完整链路与可验证性。

这些边界在 README、`docs/design.md` 与 `docs/roadmap.md` 中均已写明，不是本次申报临时补充的说明。
