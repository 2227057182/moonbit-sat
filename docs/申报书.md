## 项目定位

纯 MoonBit 的 CDCL SAT 求解器，完成「判定—证明—优化」三条链路：DIMACS CNF 判定可满足性；不可满足时输出 DRAT 日志供仓库内的独立检查器逐条复算；WCNF 加权 MaxSAT 给出最小违约成本；假设下不可满足时返回一组本身矛盾的假设。

生态中 `AdUhTkJm/sat-solver` 只支持 native 且不产出证明，`yf666888/moonsatkit` 是 DPLL 且无证明无加权，`clbbbb/lrat-check` 只有检查器。本项目在一个仓库内完成求解与验证，四后端同结果。

## 三个完整使用场景

1. **形式化验证的判定后端。** 路径条件编码成 CNF，不可达时保留证明日志并自带检查器复核；多分支组合用 `solve_core` 指出哪几条假设互斥。
2. **配置与排班的加权优化。** 硬子句写必须满足的约束，软子句写偏好，`maxsat_solve` 返回最小违约成本。
3. **算法课程参照实现。** 两文字监听、1-UIP、VSIDS、重启、归约集中在单文件，47 个测试可与真值表对拍。

## 核心功能

- DIMACS 解析与输出，变量声明不足自动扩大。
- CDCL：两文字监听、1-UIP、VSIDS、相位保存、Luby 重启、按 LBD 与活跃度归约；递归学习子句最小化。
- 增量求解与冲突预算：`solve(assumptions)`、`add_clause`、`solve_with_budget`（超预算返回 `Unknown` 并回退到 0 层）。
- DRAT 日志 + 独立检查器（`verify_proof` 严格 RUP，`verify_proof_rat` 加 RAT）；检查器自身以两文字监听推进传播，鸽巢 9/8 的 40273 行证明 32.56s → 5.96s。
- `solve_core`：沿最终冲突的 reason 图回溯，返回假设的一个子集，该子集单独回代仍然不可满足。
- 加权 MaxSAT：松弛变量 + 按权重展开 + Sinz 顺序计数编码 + 二分；下端点由 core 下界起步。
- 预处理，以及八个子命令 `solve` / `proof` / `verify` / `verify-rat` / `maxsat` / `core` / `bench` / `bench-verify`，公式内联、`;` 代替换行。

## 技术方案

纯 MoonBit，不依赖外部求解器与 FFI。`lit` 字面编码、`cnf` 结构与解析、`solver` CDCL 与证明、`checker` 独立校验、`maxsat` 加权优化，依赖单向：求解器不引用检查器，证明成立与否不依赖求解器内部状态。

47 个测试分五类：真值表枚举对拍、随机 UNSAT 证明逐条复算、随机 WCNF 与暴力枚举对拍、每个 core 单独回代必须仍不可满足、退化输入边界。wasm 与 js 全通过，四个后端构建成功。

## 原创性与生态定位

生态缺的不是又一个求解器，而是能被第三方复算的 UNSAT 证明、加权优化，以及假设级的矛盾解释。本项目补的是这三块具体能力，而非「零依赖」「统一 API」这类可替代的包装；面向验证、调度、教学三类使用者。

## 范围边界

检查器只输出 RUP，RAT 仅用于校验外部证明；MaxSAT 超权重上限直接报错；完整 OLL/WPM1 需稳定的松弛变量与权重拆解，当前只做 core 提取与下界收紧；预处理只有去重与重言消除；Luby 基数固定；预算只按冲突计；命令行内联传参；基准限于随机 3-SAT 与鸽巢，未与工业求解器同数据集对比。
