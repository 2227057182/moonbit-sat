## 项目定位

moonbit-sat 是纯 MoonBit 的 CDCL SAT 求解器，做三件事：读入 DIMACS CNF 判断可满足性；不可满足时输出 DRAT 日志，由仓库内的独立检查器逐条复算；读入 WCNF 做加权 MaxSAT，给出最小违约成本。

生态里 `AdUhTkJm/sat-solver` 是 CDCL 但只支持 native、不产出证明，`yf666888/moonsatkit` 支持四后端但是 DPLL、同样没有证明和加权优化，`clbbbb/lrat-check` 只有检查器。本项目在同一仓库里完成求解与验证，四后端行为一致。

## 三个完整使用场景

1. **形式化验证的判定后端。** 把路径条件编码成 CNF 交给 `Solver`，路径不可达时保留证明日志，用自带检查器复核结论，而不是只信求解器的返回值。
2. **配置与排班的加权优化。** 必须满足的约束写成硬子句、偏好写成带权软子句，`maxsat_solve` 返回最小违约成本，用来比较不同方案。
3. **算法课程的参照实现。** 两文字监听、1-UIP、VSIDS、重启、归约都在单个文件内，配 24 个测试与真值表对拍，可作为学生作业的参照或起点。

## 核心功能

- DIMACS CNF 解析与输出，变量声明不足时自动扩大。
- CDCL 搜索：两文字监听、1-UIP 学习子句、VSIDS、相位保存、Luby 序列重启、按 LBD 与活跃度归约。
- 递归学习子句最小化：reason 链完全被子句或 0 层覆盖的字面会被删除，`minimised` 输出累计删除量。
- 增量求解：`solve(assumptions)` 与 `add_clause`；假设冲突返回 false 但不改变求解器状态。
- 冲突预算：`solve_with_budget` 在给定冲突数后返回 `Unknown`，回退到 0 层并保留学习子句，可继续求解。
- 不可满足时输出 DRAT 日志，含学习子句、删除行与终结空子句。
- 独立检查器 `parse_drat` / `check_drat` / `verify_proof`：不引用求解器，逐条 RUP 复算，伪证明被拒绝；`check_drat_rat` / `verify_proof_rat` 追加 RAT 判定，可校验引入新变量等非 RUP 的定义步骤。
- 加权 MaxSAT：松弛变量 + 按权重展开 + Sinz 顺序计数编码 + 二分求最优。
- 预处理 `Formula::simplify`：子句内去重、删除重言子句。
- 命令行四个子命令 `solve` / `proof` / `verify` / `maxsat`，公式内联，`;` 代替换行。

## 技术方案

核心库纯 MoonBit，不依赖外部求解器，也不调用 FFI。模块按职责拆分：`lit` 字面编码，`cnf` 结构与解析，`solver` CDCL 与证明记录，`checker` 独立校验，`maxsat` 加权优化。依赖单向：求解器不引用检查器，两者只共享字面编码与公式解析，因此证明成立与否不依赖求解器的内部状态。

测试分四类：80 轮随机公式与真值表枚举对拍；40 轮随机 UNSAT 的证明逐条复算通过；40 轮随机 WCNF 的最优成本与暴力枚举一致；11 个边界测试覆盖空公式、空子句、重复文字、重言子句、变量越界等退化输入。四个后端构建成功，wasm 与 js 的同一套 24 个测试全部通过。

## 原创性与生态定位

两个已有包各缺一块：可被第三方复算的 UNSAT 证明与加权 MaxSAT 在生态中均为空白。本项目补的正是这两块，立论建立在具体能力上，而不是「零依赖」或「统一 API」这类可替代的包装理由。

项目面向验证、调度、教学三类使用者，不是只服务单一包维护者的小工具。

## 范围边界

求解器只输出 RUP 步骤，检查器另提供 RUP + RAT 模式用于校验外部证明；MaxSAT 总软权重超上限时直接报错而非截断；预处理只做去重与重言消除，没有变量消除与并行；重启用固定基数的 Luby 序列，未做自适应调整；冲突预算只按冲突数计量；命令行不支持文件 IO，改为内联传参；基准只覆盖随机 3-SAT，未与工业求解器在同一数据集上对比。以上边界在 README 与 `docs/` 中均已写明。
