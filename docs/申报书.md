## 项目定位

纯 MoonBit 的 CDCL SAT 求解器，完成「判定—证明—优化」三条链路：DIMACS CNF 判定可满足性；不可满足时输出 DRAT 日志供仓库内独立检查器逐条复算；WCNF 加权 MaxSAT 给出最小违约成本，最优性由不可达证明与可达赋值两端共同复算；假设下不可满足时返回一组本身矛盾的假设。

生态中 `AdUhTkJm/sat-solver` 只支持 native 且无证明，`yf666888/moonsatkit` 是 DPLL 且无证明无加权，`clbbbb/lrat-check` 只有检查器。本项目一仓完成求解与验证，四后端同结果。

## 三个使用场景

1. **形式化验证的判定后端。** 路径条件编码成 CNF，不可达时保留证明并复核；多分支用 `solve_core` 指出互斥的假设。
2. **配置与排班的加权优化。** 硬子句写约束，软子句写偏好，`maxsat_solve` 返回最小违约成本，`maxsat-verify` 复算最优性。
3. **算法课程参照实现。** 核心算法集中在单文件，68 个测试可与真值表对拍。

## 核心功能

- DIMACS 解析与输出，变量声明不足自动扩大。
- CDCL：两文字监听、1-UIP、VSIDS、相位保存、Luby 重启、按 LBD 与活跃度归约、递归学习子句最小化。
- 增量求解：`solve(assumptions)`、`add_clause`、`solve_with_budget`（超预算返回 `Unknown` 并回退到 0 层）。
- DRAT 日志 + 独立检查器（`verify_proof` 严格 RUP，`verify_proof_rat` 加 RAT）；检查器以两文字监听推进传播。
- `solve_core`：沿最终冲突的 reason 图回溯，返回一个单独回代仍不可满足的假设子集。
- 加权 MaxSAT：松弛变量 + 权重展开 + Sinz 顺序计数 + 二分，下端点由 core 给出。
- MaxSAT 最优性两端：`maxsat_bound_proof` 导出不可达 DRAT 并由 `verify_maxsat_bound` 复算；`maxsat_solution` 取回最优赋值，`maxsat_model_cost` 按 WCNF 重算代价（编码确定性可重建）。
- 预处理，及十五个子命令（求解、证明、检查、加权、core、编码导出、基准）；公式内联、`;` 代替换行。

## 技术方案

纯 MoonBit，无外部求解器与 FFI。模块按 `lit`/`cnf`/`solver`/`checker`/`maxsat` 划分，依赖单向：求解器不引用检查器。

68 个测试分七类：真值表对拍、随机 UNSAT 证明逐条复算、随机 WCNF 与暴力枚举对拍、每个 core 回代仍不可满足、顶点覆盖最优值与理论值对拍、下界证明正反两面（能出证 / 可达不出证 / 删空子句或借用别的 k 被拒）、最优赋值代价复算（正反两面）。wasm 与 js 全通过。

## 原创性与生态定位

生态缺的不是又一个求解器，而是可被复算的 UNSAT 证明、加权优化与假设级矛盾解释。本项目补的正是这三块能力，而非「零依赖」「统一 API」这类可替代的包装；面向验证、调度、教学。

## 验收证据

- `moon check --deny-warn` 无告警；`moon test` 68 个通过，js 后端同一套通过。
- `bench` 输出搜索量；`bench-verify <k>` 端到端求解并校验鸽巢证明，打印行数与耗时。
- 检查器实测：k=8 / 3942 行 / 0.16s，k=9 / 40273 行 / 5.96s，k=10 / 295345 行 / 350s。
- `examples/` 可跑：鸽巢证明 `s VERIFIED`，伪证明 `s PROOF-REJECTED`，加权 `o 1`，`core` 返回 `c core= 1 2 0`。
- 顶点覆盖与最优性：Petersen `o 6`、4×5 `o 10`、10×10 `o 50`（native 1.1/1.7/160ms）；`maxsat-verify` 四实例均 `c upper= true lower= true`，翻转一个变量即 `SOLUTION-REJECTED`；`k=5` 证明删末尾空子句即 `PROOF-REJECTED`。
- 外部验证：12 个证明（鸽巢 3–10、三加权下界、20×20 网格下界）交 drat-trim 与 lrat-check 复算全通过，均 0 RAT 引理的纯 DRUP，`tools/crosscheck.sh` 一键复跑。

## 范围边界

检查器只输出 RUP，RAT 仅校验外部证明；MaxSAT 超权重上限报错；最优性下界针对扩展 CNF，须用同一编码器重建；上界是求解器产出的赋值，单独不排除更低代价；完整 OLL/WPM1 未实现，只做 core 与下界收紧；预处理仅去重与重言消除；Luby 基数固定；预算按冲突计；命令行内联传参；基准限于随机 3-SAT、鸽巢与顶点覆盖（≤400 变量）。
