## 项目定位

纯 MoonBit 的 CDCL SAT 求解器，完成「判定—证明—优化」三链：DIMACS CNF 判定可满足性；不可满足时输出 DRAT 日志供仓库内独立检查器逐条复算；WCNF 加权 MaxSAT 给出最小违约成本，最优性由不可达证明与可达赋值两端共同复算；假设下不可满足时返回一组本身矛盾的假设。

生态中 `AdUhTkJm/sat-solver` 只支持 native 且无证明，`yf666888/moonsatkit` 是 DPLL 且无证明无加权，`clbbbb/lrat-check` 只有检查器。本项目一仓完成求解与验证，四后端同结果。

## 三个使用场景

1. **形式化验证的判定后端。** 路径条件编码成 CNF，不可达时保留证明并复核；多分支用 `solve_core` 指出互斥的假设。
2. **配置与排班的加权优化。** 硬子句写约束，软子句写偏好，`maxsat_solve` 返回最小违约成本，`maxsat-verify` 复算最优性。
3. **算法课程参照实现。** 核心算法集中在单文件，95 个测试可与真值表对拍。

## 核心功能

- DIMACS 解析与输出，变量声明不足自动扩大。
- CDCL：两文字监听、1-UIP、VSIDS、相位保存、Luby 重启、按 LBD 与活跃度归约、递归学习子句最小化。
- 增量求解：`solve(assumptions)`、`add_clause`、`solve_with_budget`（超预算返回 `Unknown` 并回退到 0 层）。
- DRAT 日志 + 独立检查器（`verify_proof` 严格 RUP，`verify_proof_rat` 加 RAT）；检查器以两文字监听推进传播。
- `solve_core`：沿 reason 图回溯，返回一个单独回代仍不可满足的假设子集。
- 加权 MaxSAT：编码路径（松弛 + 权重展开 + Sinz 计数 + 二分）与核心引导路径（core 记账 + 剩余权重换新松弛 + 阻塞式上界），后者无总权重上限，可设轮预算。
- MaxSAT 最优性两端：`maxsat_bound_proof` 导出不可达 DRAT 并由 `verify_maxsat_bound` 复算；`maxsat_solution` 取回最优赋值，`maxsat_model_cost` 按 WCNF 重算代价（编码确定性可重建）。
- 预处理，及十八个子命令（求解、证明、检查、加权、core、编码导出、基准）；公式内联或 `@` 读文件。

## 技术方案

纯 MoonBit，无外部求解器与 FFI。模块按 `lit`/`cnf`/`solver`/`checker`/`maxsat` 划分，求解器不引用检查器。

90 个测试分七类：真值表对拍、随机证明逐条复算、随机 WCNF 对暴力枚举、core 回代仍不可满足、顶点覆盖对理论值、下界证明正反两面、最优赋值复算；wasm 与 js 全通过。

## 原创性与生态定位

生态缺的不是又一个求解器，而是可被复算的 UNSAT 证明、加权优化与假设级矛盾解释。本项目补的正是这三块能力，而非「零依赖」「统一 API」这类可替代的包装；面向验证、调度、教学。

## 验收证据

- `moon check --deny-warn` 无告警；`moon test` 82 个通过，js 后端同一套通过。
- `bench` 输出搜索量；`bench-verify <k>` 求解并校验鸽巢证明。
- 检查器：k=8/9/10 端到端 0.7/5.7/278s，纯校验 0.16/2.5/70s（native release，单进程）。
- `examples/` 可跑：鸽巢证明 `s VERIFIED`，伪证明 `s PROOF-REJECTED`，加权 `o 1`，`core` 返回 `c core= 1 2 0`。
- 最优性：Petersen/4×5/10×10 得 6/10/50（1.1/1.7/160ms）；Petersen（权 100）`maxsat-oll` 7ms 得 `o 600`，同实例 `maxsat` 抛上限错误，20×20 加权 20 轮 <10ms 得界 `2000/40000`；`maxsat-verify` 四实例均 `c upper= true lower= true`，翻转一个变量即 `SOLUTION-REJECTED`；`k=5` 证明删末尾空子句即 `PROOF-REJECTED`。
- 外部验证：12 个证明（鸽巢 3–10、三加权下界、20×20 网格下界）交 drat-trim 与 lrat-check 复算全通过，0 RAT 引理，`tools/crosscheck.sh` 可复跑；CaDiCaL 鸽巢证明亦经本检查器通过。

## 范围边界

检查器只输出 RUP，RAT 仅校验外部证明；编码路径超权重上限报错，核心引导无上限、可设轮预算带界返回，均匀权重大图仍按层推进且不导出下界证明；下界针对扩展 CNF，须用同一编码器重建；上界单独不排除更低代价；预处理仅去重与重言消除；基准限于随机 3-SAT、鸽巢与顶点覆盖（≤400）。
