# moonbit-sat 项目申报

许可证：Apache-2.0

## 项目是什么

用 MoonBit 写的一个 SAT 求解器库，做三件事：

1. 读入 DIMACS CNF，判断公式可满足还是不可满足；
2. 不可满足时输出一份 DRAT 日志，仓库里另带一个独立的检查器，可以逐条复算这份日志；
3. 读入 WCNF，做加权 MaxSAT，给出最小违约成本。

选择这三项，是因为 MoonBit 生态里已有的两个 SAT 包缺这两块能力：`AdUhTkJm/sat-solver` 是 CDCL 但只支持 native，没有证明；`yf666888/moonsatkit` 是 DPLL，四后端但没有证明和加权优化。`clbbbb/lrat-check` 只有检查器，没有求解器。我做的是同一个仓库里既能求解、也能验证求解结果。

## 怎么用

```moonbit
let f = @moonbit_sat.parse_dimacs("p cnf 2 2\n1 2 0\n-1 0\n")
let s = @moonbit_sat.Solver::new(f)
let p = s.enable_proof()
if s.solve([]) {
  println(s.model())        // [false, true]
} else {
  println(p.text())         // DRAT 日志
}
```

命令行：

```bash
moon run cmd/main -- solve  "p cnf 3 2;1 2 0;-1 3 0"
moon run cmd/main -- proof  "p cnf 6 9;1 2 0;3 4 0;5 6 0;-1 -3 0;-1 -5 0;-3 -5 0;-2 -4 0;-2 -6 0;-4 -6 0"
moon run cmd/main -- verify "<同一公式>" "-1 0;0"
moon run cmd/main -- maxsat "p wcnf 4 7 10;10 1 2 0;10 3 4 0;10 -1 -3 0;10 -2 -4 0;3 1 0;1 -1 0;2 4 0"
```

参数里的 `;` 当作换行，公式直接内联，不需要临时文件。

## 验证过什么

- `moon check --deny-warn` 无告警，`moon test` 24 个测试通过，js 后端同一套测试也通过。
- 80 轮随机小公式与真值表枚举对拍，SAT 时检查模型确实满足每条子句。
- 40 轮随机 UNSAT 实例的证明，独立检查器逐条复算全部通过；另外有反例测试，伪造的步骤会被判失败。
- 40 轮随机 WCNF，求得的最优成本与暴力枚举一致。
- 四个后端 `moon build` 都成功。
- 从 GitHub 重新下载仓库后，`moon check` 与 `moon test` 仍然通过。

## 做不到的

- 证明只输出 RUP 步骤，不支持 RAT；
- MaxSAT 的总软权重有上限，超过上限会直接报错，不做截断；
- 没有变量消除一类的预处理（只做了子句内去重和重言消除），没有并行；
- 重启是线性增长，还没换成 Luby 序列；
- 性能没有和 MiniSat、CaDiCaL 这类工业求解器比较过，这个项目看重的是生态内的完整链路，不是极限速度。

## 仓库结构

```

checker.mbt          独立的 DRAT 解析与 RUP 校验
maxsat.mbt           WCNF 解析、Sinz 编码、二分最优
moonbit-sat_wbtest.mbt / edge_wbtest.mbt   24 个测试
cmd/main/            命令行
docs/                设计说明、API、证明格式、路线图
examples/            三个可直接跑通的实例
```
